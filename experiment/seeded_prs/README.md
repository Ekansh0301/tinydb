# Seeded pull requests (reviewer calibration)

Five pull requests with known answers, used to measure the reviewer (decision experiment E2).
Two are correct and three contain a defect that the included tests do not catch. Pull request
titles and descriptions are neutral; the labels below are kept out of the reviewer's reach
(`experiment/` is not readable by any agent tool).

See `labels.csv`. The diffs are in `diffs/`. The branches `seeded/1`..`seeded/5` stay open and are never merged.
