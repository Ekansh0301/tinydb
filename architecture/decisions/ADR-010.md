# ADR-010: Triggers, who may start a run, and concurrent runs

- **Date:** 2026-11-16
- **Status:** Accepted
- **Decision area:** D10 Triggers

## Context
The assignment names two triggers: a label on an issue and a `/autose` comment. Anyone can comment on a public repository, and a run spends limited tokens and can push branches. Two triggers for the same issue can arrive close together (label added, then a comment).

## Decision
- **Events:** `issues: labeled` with label `autose`; `issue_comment: created` where the comment body, trimmed, equals `/autose` and the comment is on an issue; the same comment on a pull request opened by this workflow requests a fresh review of that PR (stage 6 only) and counts against the two-round limit. A `workflow_dispatch` entry point exists only for the `next` job to start a later round.
- **Who:** the gate job checks the sender's repository permission through the API and requires `write` or higher. Association labels in the event payload are not trusted on their own. Everyone else gets no run and no comment.
- **Concurrency:** `concurrency: { group: autose-issue-<N>, cancel-in-progress: false }`. Runs for one issue queue. The first step of the gate reads `state.json`; if a run for the issue is already active, the new trigger exits with a one-line comment. A finished or stopped issue can be started again only by a new explicit trigger.
- **Issues are never closed or edited by the workflow.** It comments only.

## Alternatives considered
- **Trigger on every new issue.** Wastes budget and exposes the agents to all input. Rejected.
- **`cancel-in-progress: true`.** Would kill a run halfway through a push and leave a half-written branch. Rejected.
- **Trust `author_association`.** Quick, but it reflects the comment author, not the sender of a label event. We query permission instead.

## Consequences
- Only maintainers can spend tokens; it is a small, explicit trust boundary.
- A duplicate trigger is visible as a short comment, which keeps behaviour explainable.
- Comments that are not exactly `/autose` do nothing, so ordinary discussion cannot start runs.
