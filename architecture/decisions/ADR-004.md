# ADR-004: State lives in files on a separate branch, mirrored as workflow artifacts and a PR comment

- **Date:** 2026-11-16
- **Status:** Accepted
- **Decision area:** D4 State

## Context
State has to survive three things: stages that run in different jobs, review rounds that run in a different workflow run, and the restart of a failed run. Workflow artifacts expire (after 90 days by default) and are awkward to link. Putting the artifacts on the code branch would pollute the pull request diff that the reviewer is asked to judge.

## Decision
- **Durable state:** a branch `autose-runs` holds `runs/issue-<N>/round-<R>/{spec,design,test_report,pr,review}.md`, `diff.patch` and `state.json` (current stage, attempt counters, token totals, the model tier that served each call, the last gate result). It never contains source changes, so it never appears in the PR.
- **Code:** branch `autose/issue-<N>`, one per issue.
- **Mirrors:** each run uploads the same files as workflow artifacts, and the pull request carries one summary comment, edited in place, with the stage status and links.
- **Restart:** the orchestrator reads `state.json`. Stages whose gate already passed in this round are skipped, and the first stage that has not passed is run again. Running the same trigger while a run for the issue is active exits immediately (ADR-010).
- **No cache of model output.** A rerun calls the models again.

## Alternatives considered
- **Artifacts in the PR branch.** Easy to see, but it mixes process files into the diff under review. Rejected.
- **Only PR comments.** Readable by humans, but hard to parse, size-limited, and there is no PR before stage 5. Used as a mirror only.
- **Only workflow artifacts.** They are lost after the retention period and cannot be addressed from the README. Used as a mirror only.
- **Actions cache.** It can be evicted and is not meant for durable records. Rejected.

## Consequences
- Everything is linkable from `runs.md` and survives the end of the course.
- The `autose-runs` branch needs a push right for the build job; branch protection applies to `main` only.
- If `state.json` is corrupt or missing, the orchestrator stops instead of guessing.
