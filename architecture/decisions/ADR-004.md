# ADR-004: State lives in files on a separate branch, mirrored as workflow artifacts and a PR comment

- **Date:** 2026-11-16
- **Status:** Accepted
- **Decision area:** D4 State

## Context
State has to survive three things: stages that run in different jobs, review rounds that run in a different workflow run, and a restart of a failed run. Workflow artifacts expire (default 90 days) and are awkward to link. Putting artifacts on the code branch would pollute the pull request diff the reviewer is asked to judge.

## Decision
- **Durable state:** a branch `autose-runs` holds `runs/issue-<N>/round-<R>/{spec,design,test_report,pr,review}.md`, `diff.patch` and `state.json` (current stage, attempt counters, token totals, model tier served per call, last gate result). It never contains source changes, so it never appears in the PR.
- **Code:** branch `autose/issue-<N>`, one per issue.
- **Mirrors:** each run uploads the same files as workflow artifacts, and the pull request carries one summary comment, edited in place, with stage status and links.
- **Restart:** the orchestrator reads `state.json`. Stages whose gate already passed in this round are skipped; the first not-passed stage is re-run. Re-running the same trigger while a run for the issue is active exits immediately (ADR-010).
- **No cache of model output.** A rerun calls the models again.

## Alternatives considered
- **Artifacts in the PR branch.** Easy to see, but mixes process files into the reviewed diff. Rejected.
- **Only PR comments.** Readable by humans, hard to parse, size-limited, and no PR exists before stage 5. Used as a mirror only.
- **Only workflow artifacts.** Lost after retention and not addressable from the README. Used as a mirror only.
- **Actions cache.** Evictable and not meant for durable records. Rejected.

## Consequences
- Everything is linkable from `runs.md` and survives the end of the course.
- The `autose-runs` branch needs a push right for the build job; branch protection applies to `main` only.
- If `state.json` is corrupt or missing, the orchestrator stops rather than guessing.
